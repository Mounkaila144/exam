## 2026-05-23 — Discovery (réponses utilisateur, batch 2 — rectifications)

- **"INSAS"** : nom abandonné. Codename de travail retenu = **"ExamGuard"**. Décision : nom final à arrêter avant déploiement public (cf. `Risks & Open Questions` du brief).
- **Clé API Anthropic** : **mutualisée au niveau plateforme**, payée par l'administrateur. **Pas de clé par prof.** Conséquences :
  - Schéma DB simplifié : suppression table `api_keys`, remplacée par `platform_settings` (clé chiffrée unique) + `api_usage_log` (traçabilité par prof).
  - Risque coût : ajouté aux Open Questions ; mitigation MVP = dashboard consommation + estimation coût avant appel ; V2 = quotas par prof.
- **Administrateur** : **un seul super-admin global** (Mounkaila). Pas de multi-admin / multi-institution au MVP. Rôle admin = (1) validation inscriptions profs, (2) gestion clé API plateforme, (3) monitoring consommation.
- **Examen "Transformation Digitale" existant** : **non migré**. On repart d'une base vide. Conséquences :
  - Table `submissions` actuelle → drop + reconstruction.
  - Routes `/api/submit-exam` publiques → supprimées.
  - Code existant sert de référence (pattern auto-correction, format export Claude) mais refactor complet.
